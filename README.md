# Daisyy — Artist Portfolio (React + Tailwind + react-icons)

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
npm run preview
```

Artwork images live in `public/images/`. Site content (artworks, prices, terms, nav links) is centralized in `src/data.js` — edit that file to update the site.
